## 可重复只读审计

在已校验的 SQLite 快照上运行：

	env PYTHONDONTWRITEBYTECODE=1 python3 scripts/audit-financial-history.py --database /secure/path/snapshot.db

脚本以 mode=ro 和 query_only 打开数据库，用单个读事务检查计费三方差额、重复流水、冻结额与未结算预扣一致性、保留日志中的缺账以及历史对账异常，并比较日结单的笔数/毛额与源账单。日结比较使用数据库中保存的业务本地日期，不做 SQLite UTC 日期转换；仅适用于历史时间戳业务时区一致的库，退款扣减和月结仍需单独核查。输出包含内部用户/请求 ID 和财务信息，应保存到权限 0600 的受控文件，不提交报告到公共 Git。它不迁移结构、不生成单据、不发告警、更不应用修正。输出无异常不证明已归档历史完整。

测试：

	python3 -m unittest discover -s scripts -p test_financial_audit.py -v
